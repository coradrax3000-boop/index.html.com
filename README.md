# 🍁 Aula Abierta

Blog interactivo con las reflexiones y aprendizajes de nuestro equipo como futuros profesionales de la educación. Es un proyecto de clases hecho en una sola página web (HTML, CSS y JavaScript), sin dependencias ni instalación.

🔗 **Ver el blog:** _https://github.com/coradrax3000-boop/index.html.git_

## 📚 Contenido

El blog reúne 8 entradas, cada una con su reflexión, competencias desarrolladas y una pregunta para los lectores:

1. Mi aprendizaje y reflexión como futuro profesional de la educación
2. La tecnología como herramienta para aprender
3. Gestión escolar y liderazgo educativo
4. El papel de la psicología educativa en la escuela
5. La planeación didáctica y las estrategias de enseñanza
6. Educación especial e inclusión educativa
7. Teorías psicológicas del aprendizaje
8. La importancia de la educación en la sociedad

## ✨ Funciones interactivas

- Presentación del equipo con diapositivas
- Mini quiz de 2 preguntas por entrada
- Insignias de lectura
- Línea de tiempo animada de las teorías del aprendizaje
- Glosario con globitos de definición
- Mapa conceptual interactivo que conecta los temas
- Selector de temas: otoño, primavera y nocturno
- Búho animado que acompaña la lectura
- Competencias que se pueden marcar, reacciones y comentarios
- Animaciones de bienvenida y despedida
- Modo enfoque, que apaga las animaciones para leer con calma

Las insignias, los puntajes, los comentarios y el tema elegido se guardan solo en el navegador de cada lector.

## 🚀 Cómo verlo

**En tu computadora:** descarga `index.html` y ábrelo con doble clic en cualquier navegador.

**En internet con GitHub Pages:**

1. Sube el archivo `index.html` a este repositorio.
2. Ve a **Settings → Pages**.
3. En **Branch**, elige `main` y la carpeta `/ (root)`, y guarda.
4. Espera uno o dos minutos y GitHub mostrará el enlace público.
